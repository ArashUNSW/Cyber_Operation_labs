# Ethics and Responsible Use Statement

## Purpose of This Lab Series

The BlueWave Clinic Cyber Operations with Elastic lab series is designed for **defensive cybersecurity education only**.

The purpose of these labs is to help students learn how to:

- Monitor endpoint activity.
- Collect and review Windows and Sysmon logs.
- Use Elastic and Kibana for investigation.
- Identify suspicious-looking but safe activity.
- Build simple detection logic.
- Practise incident triage and reporting.
- Develop responsible SOC analyst skills.

This course must not be used to teach, practise, or support offensive cyber activity.

---

## Authorised Use Only

Students must use this lab environment only inside the approved Skillable training environment.

Students must not use the lab instructions, tools, queries, commands, or techniques against:

- Public systems.
- Employer systems without written permission.
- School or university networks without authorisation.
- Cloud environments not assigned for this course.
- Personal devices belonging to others.
- Any system they do not own or have explicit permission to test.

> [!warning]
> Cybersecurity skills must only be used in environments where you have clear permission. Unauthorised access, scanning, monitoring, or testing may be illegal and may result in disciplinary, civil, or criminal consequences.

---

## Defensive Scope

This lab series is strictly limited to defensive security operations.

Allowed activities include:

- Reviewing logs.
- Searching events in Kibana.
- Analysing Windows Event Logs.
- Analysing Sysmon process creation events.
- Running approved safe lab simulations.
- Creating detection queries.
- Writing incident notes and reports.
- Practising triage and response documentation.

Not allowed activities include:

- Malware execution.
- Exploit development or exploitation.
- Credential theft.
- Password attacks.
- Brute-force activity.
- Persistence testing.
- Privilege escalation.
- Evasion testing.
- Public internet scanning.
- Attacking other students’ systems.
- Modifying lab tools for harmful use.
- Using offensive frameworks or unauthorised tools.
